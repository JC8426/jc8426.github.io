# Revision 4 — cinematic patrol / interactive flight

- Default: closed figure-eight route from the supplied XY waypoints, automatic wide / broadcast / tracking / onboard shots; fleet telemetry only, controls hidden and inert.
- Explore: explicit entry, stable camera controls, physical WASD/QE/RF keys independent of canvas focus, individual pilot, waypoint dispatch, five-aircraft A / line / S / matrix layouts.
- Exit: resume patrol smoothly; clear held input, keep page scroll position.
- Terrain: larger world, smooth multi-scale landforms and photographic PBR surface; no claim that a procedural scene equals a photogrammetry scan.
- Engineering: pure simulation tests, real browser inspection of both themes and interaction, source-backed EGO portability and memory budget.
- Coordinate convention: the supplied XY route maps to world XZ; its Z=1 is relative to the initial cruise clearance (4.3 m), so patrol clearance is 5.3 m above local terrain. This is illustrative terrain following, not an EGO controller.
