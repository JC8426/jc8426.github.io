Embedded systems / Monitoring

From a sensor reading to a useful view.

My final-project work introduced a pipeline from lower-machine sensing through remote transmission and database storage to a monitoring interface. I later considered how the same structure could support agricultural monitoring.

01 / Context

The question behind the work.

The original context was mine gas monitoring: collect a reading, transmit it remotely, store it and make it available through an interface. I mapped this sensing-to-database-to-interface pipeline as part of my final-project work.

Agricultural irrigation raises related questions about measurements, history and remote observation. I explored the transfer at the system-logic level: which parts of the data path remain useful when the sensor and application change.

02 / Practice

How I approached it.

01

Sense

02

Transmit and store

03

Review

Present current and historical readings in a monitoring interface.

The transferable idea is the data path. A change of application also changes the sensor requirements, sampling assumptions and decisions made from the readings. Those details would need to be designed and tested for an agricultural implementation.
